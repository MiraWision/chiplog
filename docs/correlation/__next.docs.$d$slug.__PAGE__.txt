3:T2d7d,<h1 id="correlation-and-traceparent"><a class="anchor" href="#correlation-and-traceparent" aria-label="Link to this section">Correlation and traceparent</a></h1><h2 id="one-id-per-operation"><a class="anchor" href="#one-id-per-operation" aria-label="Link to this section">One id per operation</a></h2><p>Every event carries a <code>correlationId</code>, shared by every flow belonging to the same logical operation,
and a <code>flowId</code> unique to that flow. Where an operation spans more than one flow — nested calls, a
queue hop — those two fields are what join them back together.</p>
<p>chiplog does not invent a carrier format. What crosses a boundary is a standard <strong>W3C
<code>traceparent</code></strong>, so it interoperates with OpenTelemetry and with every proxy that already forwards
the header.</p>

<span class="line"><span style="--shiki-light:#AF00DB;--shiki-dark:#C586C0">await</span><span style="--shiki-light:#001080;--shiki-dark:#9CDCFE"> chiplog</span><span style="--shiki-light:#000000;--shiki-dark:#D4D4D4">.</span><span style="--shiki-light:#795E26;--shiki-dark:#DCDCAA">run</span><span style="--shiki-light:#000000;--shiki-dark:#D4D4D4">(</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178">"orders.create"</span><span style="--shiki-light:#000000;--shiki-dark:#D4D4D4">, </span><span style="--shiki-light:#001080;--shiki-dark:#9CDCFE">handler</span><span style="--shiki-light:#000000;--shiki-dark:#D4D4D4">, </span><span style="--shiki-light:#001080;--shiki-dark:#9CDCFE">seed</span><span style="--shiki-light:#000000;--shiki-dark:#D4D4D4">);</span></span></code></pre></div><p>In priority order:</p>
<ol>
<li>a valid <code>traceparent</code> — its trace id becomes the correlation id, and the trace continues;</li>
<li><code>x-correlation-id</code>, then <code>x-request-id</code>;</li>
<li>otherwise a fresh id is generated.</li>
</ol>
<p>A malformed or all-zero <code>traceparent</code> is ignored rather than adopted, so a broken upstream starts a
clean trace instead of poisoning the field for everything downstream.</p>
<div class="callout callout-pass"><p class="callout-label">Tip</p><p>Return the id to the caller. Both adapters set <code>x-correlation-id</code> on the response, which means a
user reporting &quot;it failed at 14:32&quot; can hand you the exact record.</p>

<p>Use nesting when a sub-operation deserves its own timing and outcome. Use stages when it does not.</p>
<div class="callout callout-brand"><p class="callout-label">Note</p><p><code>begin()</code> — the manual primitive used by hook-based adapters — never adopts an ambient parent. It

visible; inheriting would chain every request in a process onto the first one&#39;s correlation id.</p>
